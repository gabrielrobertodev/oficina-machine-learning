**Oficina de Machine Learning com Python**

Sobre o projeto

Este repositório reúne o código desenvolvido durante uma oficina introdutória de Machine Learning, realizada no evento WECTI.

A atividade teve como objetivo proporcionar um primeiro contato com conceitos de Inteligência Artificial e Aprendizado de Máquina, utilizando a linguagem Python.

Tecnologias utilizadas

* Python: linguagem utilizada no desenvolvimento da atividade.
* Machine Learning: conceitos introdutórios de aprendizado de máquina.
* Inteligência Artificial: área de estudo relacionada ao desenvolvimento da oficina.

Arquivos do projeto

* machine_learning.py — código desenvolvido durante a oficina.

Objetivo acadêmico

Esta atividade representa uma oportunidade de ampliar meus conhecimentos em tecnologia, explorar aplicações de Inteligência Artificial e conhecer conceitos de Machine Learning na prática.

Como estudante de Análise e Desenvolvimento de Sistemas (ADS), considero essa experiência parte importante da minha evolução e do meu aprendizado em programação.
